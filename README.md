# 虚拟文档树 / Virtual Document Tree

> 类 Obsidian 虚拟文档树 + 类 VSCode 文件编辑器套件,为思源笔记打造。

把思源文档/笔记本、本地文件夹、百度网盘挂载到同一棵树里,用 Monaco / Vditor / Notebook /
图片 / 音视频 / Office 等页签直接打开编辑,另有新标签页(启动台)、内置终端、全局搜索、
版本比较、回收站、标签系统等完整配套。

## 功能 / Features

- **虚拟文档树**:把思源文档/笔记本、本地文件夹、百度网盘目录挂载到一棵树里,与真实文件并存;懒加载展开、拖拽排序、右键全套文件操作(新建/重命名/删除/复制路径/打开方式/终端…);工具栏可标签筛选、刷新引用关系、全部收起,以及**定位当前文档**——点击固定/最近里的思源文档、笔记本或文件夹时,树会自动展开到对应位置并闪烁提示
- **新标签页(启动台)**:接管思源顶部「+」(可在设置中还原);顶部文件搜索(↑↓ 选择、回车打开);**固定 / 最近打开 / 收藏**三个分区,支持自定义图标(文档树同款)、点击直接打开并在虚拟文档树中定位
- **多标签代码编辑器**(VSCode 式):Monaco Editor 提供语法高亮、代码折叠、智能提示、minimap;支持滚动越过最后一行(与 VS Code 一致),`Ctrl+S` 保存
- **Markdown 编辑器**:Vditor 实时预览 / 阅读模式,标题面包屑可逐级下钻跳转;每次保存自动留存版本快照,可在对话框或独立页签中做并排/内联**差异比较**,并一键恢复任一侧
- **Notebook**:`.ipynb` 查看与编辑,支持选择内核执行
- **图片查看**:独立 Tab 打开,支持缩放、旋转、拖拽平移、同目录上一张/下一张、复制与另存为
- **音视频 / Office**:音视频播放 Tab;常见 Office 文档以只读方式预览
- **内置终端**:真 PTY(PowerShell / bash),可从任意目录打开,多个终端以页签管理
- **代码块运行**:思源正文里的 Python 代码块一键运行,输出显示在代码块下方
- **全局搜索**:`Ctrl+Shift+F` 跨文件内容搜索,支持大小写/全词/正则、包含与排除通配符(`*.md`、`node_modules/**`)、上下文行,结果按文件分组折叠;范围可切到「虚拟文档树」,直接搜挂载的思源文档与块并跳转定位
- **回收站**:删除二选一(设置 → 删除方式)。「插件回收站」把文件按**原路径镜像**存放在工作空间 `.siyuan/virtual-tree-trash/`,可查看、一键恢复到原位置、彻底删除或清空;「系统回收站」交给操作系统管理。原位置已有同名文件时恢复为「xxx (恢复 时间)」,永不覆盖现有文件;百度网盘文件走网盘删除,由网盘回收站兜底
- **标签系统**:给文件/思源文档打标签,标签面板集中浏览,虚拟文档树可按标签筛选
- **图标主题**:支持安装 VSCode 图标主题扩展,文件树、页签、新标签页的图标保持一致
- **百度网盘挂载**:把网盘文件和文件夹(含同步空间)挂进树里,浏览、编辑并保存回网盘
- **主题同步**:编辑器代码主题与图标主题可独立选择,明暗模式跟随思源
- **设置面板**:字体大小、Tab 宽度、自动换行、minimap、历史版本数量、删除方式等可配置

## ⚠️ 谨慎使用

本插件直接读写磁盘上的真实文件,日常重度使用前请先了解这些行为:

- **删除统一走回收站(没有直接删除)**:「插件回收站」按原路径镜像存放在工作空间 `.siyuan/virtual-tree-trash/`,设置 → 回收站里可一键恢复到原位;「系统回收站」到系统里恢复。回收站内「彻底删除/清空」才不可恢复;百度网盘文件走网盘删除(由网盘回收站兜底);
- **保存即覆盖,网盘尤甚**:所有保存都直接覆盖磁盘/云端原文件。编辑百度网盘文件后保存会**覆盖云端原文件**,普通账户没有历史版本可回滚,不确定就先下载一份副本;
- **历史版本不是备份**:每文件默认只保留最近 10 条(设置里可调,0 = 关闭),历史总占用超限还会自动丢弃最老的——它只用于抵御手滑误改,不能替代备份/同步;
- **终端、代码块运行与「打开方式」会在系统上执行真实程序**:内置终端跑 shell、正文 Python 代码块真实执行、自定义「打开方式」拉起外部应用——只运行/打开你看得懂的内容;
- **接管打开会改变思源默认行为**:文档内 `assets/`、`file://` 链接改用本插件页签打开(设置里可关),行为异常时可先关掉接管排查;
- 建议先把工作空间接入**思源同步/快照**,或把 `data/` 纳入 git,再开始重度使用。

### 百度网盘挂载

1. 文件树工具栏点击「云」图标(或设置 → 百度网盘 → 百度网盘账号…),选择接入方式:
   - **官方 API(推荐)**:到 [百度网盘开放平台](https://pan.baidu.com/union/doc) 注册开发者并创建应用,把 AppKey/SecretKey 填入插件后点「获取授权」,在百度页面输入验证码确认即可(令牌 30 天有效,自动续期)。注意:未过审应用仅能访问网盘「我的应用数据 `/apps/<应用名>/`」目录,且官方 API 无同步空间接口。
   - **网页 Cookie**:登录 pan.baidu.com 后 F12 → 应用 → Cookies 复制 `BDUSS` 与 `STOKEN`。全盘可访问,支持同步空间(默认对应云端 `/apps/sync`,可在设置中调整),但属非官方接口,请勿高频操作以免触发风控。
2. 在弹出的对话框中选择挂载目标:一键挂载「同步空间」(Cookie 模式),或逐层浏览「全部文件」后挂载任意文件夹;也可把网盘目录挂载到虚拟文档树的任意真实目录下(与本地文件并存)
3. 挂载后即可浏览网盘目录、打开文件(Markdown/文本/图片/音视频/Office),编辑保存自动上传回网盘(覆盖原文件);支持新建、重命名、删除

说明:上传/下载无代理限制需使用思源桌面端,浏览器端经内核代理(响应上限 32MB、暂不支持上传)。

## 快捷键 / Shortcuts

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + S` | 保存当前文件 |
| `Ctrl/Cmd + Shift + F` | 全局搜索 |
| `F2` | 重命名(文件树中) |

图片查看 Tab 内的快捷键:

| 快捷键 | 功能 |
|--------|------|
| `+` / `-` | 放大 / 缩小(以指针为中心) |
| `0` | 恢复 100% |
| `/` | 适应窗口 |
| `R` | 旋转 90° |
| `←` / `→` | 上一张 / 下一张(同目录) |

鼠标:滚轮缩放,双击在「100% ↔ 适应窗口」间切换,按住左键拖拽平移。

## 安装 / Install

1. 下载 `package.zip`
2. 思源 → 设置 → 集市 → 下载 → 从本地安装,选择解压后的目录
3. 启用插件

## 开发 / Development

```bash
npm install
npm run dev   # 监听构建,输出到思源插件目录(直接生效)
```

在思源中通过「本地插件」加载本项目目录即可调试。

```bash
npm run build      # 生产构建,输出到 dist/(构建前自动清空,只含插件打包文件)
npm run zip        # 将 dist/ 打包为 build/package.zip
npm run package    # 构建 + 打包(一条命令)
```

## 说明 / Notes

- 仅支持桌面端
- 本地文件浏览范围默认限定在工作空间 `data/` 目录,其他位置通过「挂载文件夹」加入
- 思源文档/笔记本的挂载是元数据,不移动、不复制文件;编辑挂载的思源文档会写回思源
- 图片(png/jpg/gif/webp/svg/avif 等)以图片查看 Tab 打开,其余二进制文件不在编辑器中打开
- 同一文件在多 Tab 间共享同一编辑模型
- 图标主题为可选扩展,未安装时使用思源内置图标;安装后文件树、页签、新标签页图标保持一致
