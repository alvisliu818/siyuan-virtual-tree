# 虚拟文档树

思源笔记插件，根据文档首块链接关系构建虚拟文档树面板。

与传统按笔记本物理层级组织的文档树不同，本插件通过解析文档**首块的引用链接**自动构建一棵虚拟关系树，让你能够按文档间的引用关系浏览和组织内容，而非受限于笔记本的原生层级。

## 功能特性

- **虚拟树构建**：基于文档首块引用关系自动构建父子层级，支持重名文档（通过文档 ID 区分）
- **多入口添加根节点**：文档树右键菜单、编辑器标题右键菜单、命令面板均可添加/移除根节点
- **聚焦当前文档**：一键只显示当前激活文档的后代树，便于专注浏览
- **定位当前文档**：在虚拟树中快速滚动定位到当前激活文档
- **物理子树合并**：可选将文档在思源原生层级的物理子文档也作为虚拟子节点显示
- **多种排序方式**：按名称、按自定义权重属性、或自定义拖拽排序
- **自动刷新**：监听 ws 事件，文档增删改移后自动重建树
- **多标签页支持**：在多标签页环境下准确识别当前激活文档
- **悬浮提示**：鼠标悬停显示文档名 + ID，以及笔记本 > 父文档的物理路径
- **折叠状态持久化**：折叠/展开状态跨会话保留
- **可配置展开层级**：默认展开层级、最大递归深度、最大节点数等防失控设置

## 使用方法

### 添加根节点

任选其一：

1. 在思源文档树中右键文档 → **添加到虚拟文档树**
2. 在编辑器标题图标上右键 → **添加到虚拟文档树**
3. 命令面板执行 **将当前文档添加为根节点**

### 打开虚拟树面板

插件加载后，虚拟文档树面板会出现在左侧下方停靠栏（`LeftBottom` 位置），点击图标展开。

### 工具栏功能

| 图标 | 功能 |
| --- | --- |
| 刷新 | 重新构建虚拟树 |
| 折叠全部 | 折叠所有有子节点的节点 |
| 展开全部 | 展开所有节点 |
| 定位当前文档 | 滚动定位到当前激活文档 |
| 聚焦当前文档 | 只显示当前激活文档的后代树；再次点击退出聚焦 |

### 右键菜单

在虚拟树节点上右键：

- **打开文档**：在当前标签页打开
- **在新标签页打开**
- **从虚拟树移除**（仅根节点）

## 设置项

在 `设置 → 集市 → 已下载 → 虚拟文档树` 中配置：

| 设置项 | 说明 |
| --- | --- |
| 权重属性名 | 文档自定义属性中用于排序的权重字段名，缺失则权重视为 0 |
| 默认展开层级 | `0` = 全部折叠，`-1` = 全部展开，`N` = 展开前 N 层 |
| 排序方式 | 按名称 / 按权重 / 自定义排序（拖拽） |
| 最大递归深度 | 构建子树时的最大递归层数，防止无限递归 |
| 最大节点数 | 虚拟树的最大节点总数，超出则停止构建 |
| 占位文字 | 树为空时显示的文字 |
| 区分大小写 | 排序时是否区分大小写 |
| 包含物理子树 | 开启后，文档在思源原生层级的物理子文档也会作为虚拟子节点显示 |

## 工作原理

1. **根节点**：用户显式添加的文档作为虚拟树的根
2. **父子关系**：扫描所有文档的**首块**（按 `sort` 最小的非文档块），解析其中包含的引用链接（`refs` 表），被引用文档作为父，引用文档作为子
3. **去重合并**：合并 4 套 SQL 策略的结果，避免单一策略漏掉部分引用关系
4. **物理子树（可选）**：开启后同时拉取文档在思源原生层级的物理子文档，与引用关系合并去重

> 注：本插件通过文档 ID 维护树结构，重名文档不会冲突。

## 开发

### 环境要求

- Node.js
- npm

### 脚本

```bash
# 安装依赖
npm install

# 开发模式（监听变更输出到 .src）
npm run dev

# 构建并打包（输出 dist/package.zip）
npm run build

# 仅打包
npm run zip

# 清理产物
npm run clean
```

### 构建产物

- `npm run dev` / `npm run build`：TypeScript + SCSS 编译输出到 `.src/` 目录
- `npm run build`：进一步通过 `scripts/zip.js` 将 `.src/` 打包为 `dist/package.zip`，符合思源插件市场格式

产物结构：

```
dist/package.zip
├── plugin.json
├── index.js
├── index.css
└── i18n/zh_CN.json
```

### 模块结构

```
src/
├── index.ts          插件入口，注册 dock / 命令 / 事件
├── panel.ts          面板 UI 与交互逻辑
├── treeBuilder.ts    虚拟树构建逻辑（合并引用关系 + 物理子树）
├── api.ts            SiYuan API 封装（SQL 查询、文档信息、引用关系）
├── stateManager.ts   状态管理与持久化（设置/根文档/折叠状态/自定义排序）
├── settings.ts       设置面板 UI
├── sorter.ts         排序实现
├── disambiguator.ts  重名文档消歧
├── constants.ts      常量（dock 类型、存储名、命令键、时间常量）
├── i18n.ts           翻译辅助函数
├── types.ts          类型定义
├── utils.ts          通用工具（当前文档识别、右键菜单注入、防抖）
└── index.scss        样式
```
